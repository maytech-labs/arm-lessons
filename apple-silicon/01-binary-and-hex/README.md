# Lesson 01 on macOS: Binary and hexadecimal

Nothing differs. Binary, hex, sizes, and unsigned arithmetic are the same on
every computer, and the Arm names (byte, halfword, word = 32 bits,
doubleword) are the same on macOS.

Do [the main lesson](../../lessons/01-binary-and-hex/README.md) and its
[exercises](../../lessons/01-binary-and-hex/exercises.md). The checking
commands in the lesson (`echo $((0x2A))`, `printf '%x\n' 42`, and `bc`) all
work in macOS Terminal.
