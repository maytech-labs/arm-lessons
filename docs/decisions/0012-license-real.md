# 0012: License the course under REAL 1.0

- **Status:** Accepted
- **Date:** 2026-10-28

## Context

The course is to be published. Without a license, nobody may legally reuse
it.

## Decision

The whole repository (prose, programs, scripts) is licensed under the
Reciprocal Ethical AI License, REAL 1.0, from
[maytech-labs/real-license](https://github.com/maytech-labs/real-license). The
full text is in `LICENSE.md` at the repository root.

REAL 1.0 grants free use, modification, and redistribution, with reciprocal
(copyleft) terms for modified versions, reciprocal terms for machine-learning
training on the material, and ethical-use restrictions.

## Alternatives considered

- **CC BY-SA 4.0 (prose) + MIT (code)** - the common split for tutorials, but
  without the project's AI-reciprocity and ethical-use terms.
- **MIT for everything** - simplest, least restrictive.

## Consequences

The project is *source-available*, not open source in the OSI sense; the README
says so. Contributions are accepted under the same license (see
`CONTRIBUTING.md`).
